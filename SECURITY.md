# Security Policy

## Supported Versions
We actively maintain and provide security patches for the following versions of `karpwiki`:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability
**Please do not report security vulnerabilities through public GitHub issues.** 

If you discover a security flaw related to the OIDC authentication layer, Redis-backed rate limiting, or PII detection engines, please report it via one of the following methods:
1. Open a private vulnerability report directly through the GitHub **Security** tab of this repository.
2. Email the maintainer team directly at: mailto.deepakp@gmail.com.

We take security seriously and will acknowledge your report within 48 hours and coordinate a private fix before public disclosure.
